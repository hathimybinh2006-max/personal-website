# Trang Web Cá Nhân (Personal Website)

Bài thực hành thiết kế trang web cá nhân áp dụng tổng hợp các kiến thức HTML và CSS.

## Nội dung bài tập
- **Tiêu đề chính**: Header màu xanh `#4CAF50` nổi bật với chữ trắng.
- **Ảnh đại diện (`avatar.jpg`)**: Được bo tròn thành hình tròn hoàn hảo (`border-radius: 50%`) với viền xanh.
- **Giới thiệu bản thân**: Đoạn văn giới thiệu họ tên và đam mê công nghệ.
- **Danh sách sở thích**: Sử dụng thẻ `<ul>` và `<li>` với dấu đánh dấu hình vuông (`list-style-type: square`).
- **Mục tiêu học tập**: Đoạn văn bản định hướng tương lai nghề nghiệp lập trình viên.
- **Bảng thông tin liên hệ**: Bảng HTML với `border-collapse: collapse`, tiêu đề xanh, liên kết mạng xã hội và email.
- **Footer**: Chân trang định dạng màu nền `#e0e0e0` trang nhã.
